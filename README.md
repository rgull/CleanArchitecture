# Introduction

Finyx - Saas software to create and facilitate the annual report process.

Goals:

- Phase 0: Setup Infrastructure and Codebase
- Phase 1: MVP - Simple Report
- Phase 2: MVP+ - Report Look and Feel
- Phase 3: Workflow Support
- Phase 4: Consolidation of buinesses
- Phase 5: Decouple from Asperion
- Phase 6: Reporting and Dashboarding
- Phase 7: AI analysis
- Phase 8: CRM functions (Planning, Timeregistration)

## Getting Started

Software Requirements:

1. Installation process
    - Sonarcloud is needed inside of IDE
2. Software dependencies
    - OpenTelemetry for Tracing, Logging and Metrics
    - Docker and/or Docker Compose
    - Azure Key Vault connectivity for Secrets at Runtime
3. Database Technology:
    - State Based: Entity Framework Core with SQL Project inside of Visual Studio: <https://erikej.github.io/efcore/dacpac/2024/02/11/powertools-dacpac.html>
